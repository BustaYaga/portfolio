Summary

Touch is an Easy Windows machine, themed like the earlier Layover box: access is over RDP into a locked-down kiosk environment. A "DeviceHub" scanner web app on port 8443 leaks device metadata at /api/status, including a hardware serial that doubles as the login secret. Authenticating to the web app exposes plaintext RDP credentials for KioskUser. From the kiosk desktop — a constrained plane-ticket booking app — the attached scanner can be powered off through the same web app, forcing the kiosk into an error state with a clickable redirect that opens Internet Explorer. A file:// URI to cmd.exe then breaks out of the kiosk into a command prompt, where the user flag is read.

Initial Access

Leaked Device Serial

Fuzzing the DeviceHub app with ffuf surfaces an /api/status endpoint that returns device metadata without authentication — including the hardware serial:

curl -i http://touch.htb:8443/api/status

HTTP/1.1 200 OK
Content-Type: application/json
Server: Microsoft-HTTPAPI/2.0

{"device":"Nexion DeviceHub DH-100","serial":"NX-DH-2024-B7042","firmware":"1.4.2","status":"online","uptime":77142}

The serial NX-DH-2024-B7042 is accepted as the DeviceHub login secret. Once authenticated, the app displays the RDP credentials for the kiosk account in plaintext:

UsernamePasswordService
DeviceHub loginNX-DH-2024-B7042 (device serial)DeviceHub web app (8443)
KioskUserK!0sk2026#RDP kiosk desktop

RDP into the Kiosk

Connecting over RDP with xfreerdp lands on a locked-down plane-ticket booking kiosk, using the KioskUser credentials recovered above.

xfreerdp /v:touch.htb /u:KioskUser /p:'K!0sk2026#' /cert:ignore

Kiosk Breakout → User

The kiosk is tied to an attached scanner. Powering the scanner off from the DeviceHub web app (already authenticated earlier) forces the kiosk app into an error state, which renders a clickable redirect link. Following that link opens Internet Explorer inside the otherwise locked session.

With a browser available, an file:// URI pointing at cmd.exe escapes the kiosk and spawns a command prompt:

file:///C:/Windows/System32/cmd.exe

From the command prompt the user flag is accessible:

type C:\Users\KioskUser\Desktop\user.txt
---CENSORED---

If a more comfortable shell is needed, a standard PowerShell reverse shell one-liner can be launched from the same prompt to a netcat listener.

Notes

This writeup documents the chain from the leaked serial through the kiosk breakout to the user flag. The root portion is not covered here.
